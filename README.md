# MAD Lab — Public

Public experiments and reusable engineering patterns from MAD Lab.

**Experimental by default. Public does not imply canonical, validated, or maintained OSS.**

This repository is a deliberately narrow public surface. It exposes artifacts that can be tried, used, challenged, or falsified without publishing MAD Lab's private project state or internal control plane.

- [Evidence-Carrying Handoff v0.1](patterns/evidence-carrying-handoff/) — an experimental transfer record for preserving evidence, assumptions, failures, blockers, uncertainty, artifacts, and the next test across execution boundaries.

### TRY — Experiments

- [Dynamic OS / Quiet Threshold](experiments/dynamic-os/quiet-threshold/) — provenance recovery in progress; the interaction will not be reconstructed from memory or screenshots.

## Evidence boundary

A public artifact may be experimental, synthetic, internally tested, externally tested, or validated. Those states are not interchangeable.

Publication is not evidence of usefulness. Agreement is not validation. A working implementation is not proof of outcome.

## Authority boundary

Nothing in this repository grants authority over private MAD Lab systems, projects, accounts, capital, devices, credentials, or production environments.

## Maintenance boundary

Unless a specific artifact says otherwise, publication here does not create a support promise, roadmap, compatibility guarantee, or maintained-OSS commitment.
